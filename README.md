# LRC Studio 5.0

Локальный редактор для автоматической пословной синхронизации песен и ручной доводки Enhanced LRC (ELRC).

## Что умеет

- выравнивает точный текст песни по аудио через `py-roller`;
- при необходимости отделяет вокал через Demucs;
- ищет текст в LRCLIB, BetterLyrics, Musixmatch и NetEase;
- принимает MP3, WAV, FLAC, M4A, AAC, OGG и OPUS до 200 МБ;
- импортирует существующие LRC/ELRC, включая A2 и foobar2000-варианты;
- показывает караоке-предпросмотр и форму волны;
- позволяет поставить начало/конец слова прямо по позиции плеера;
- поддерживает отмену/повтор, общий сдвиг, добавление и разделение строк;
- проверяет порядок, пересечения и пустые тайминги;
- экспортирует три независимых результата.

## Форматы экспорта

1. **Точный ELRC (`.elrc`)** — миллисекунды и парные таймкоды начала/конца каждого слова. Сохраняет реальные паузы и точную длительность всех слов.
2. **Совместимый ELRC (`.elrc`)** — сотые доли секунды, таймкоды перед словами без конечного пустого маркера. Подходит для большинства ELRC-плееров.
3. **Обычный LRC (`.lrc`)** — один таймкод на строку.

Пример точного ELRC:

```text
[ar:Artist]
[ti:Song]

[00:12.340]<00:12.340>Первое <00:12.700> <00:12.810>слово <00:13.220>
```

## Установка на Windows

Рекомендуется Python 3.11 x64, Node.js и NVIDIA GPU. Нужен `ffmpeg` в `PATH` либо файлы `ffmpeg.exe`/`ffprobe.exe` в папке `ffmpeg\bin` проекта.

1. Запусти `setup.bat`.
2. После установки запусти `run.bat`.
3. Открой `http://127.0.0.1:5000`.

`requirments.txt` сохранён для совместимости со старым запуском и подключает правильный `requirements.txt`.

## Как получить лучший результат

1. Загрузи исходный аудиофайл без перекодирования, если он доступен.
2. Вставь проверенный текст с правильными переносами строк. Это важнее автоматического распознавания.
3. Оставь Demucs включённым для плотных аранжировок и фонового вокала.
4. После автоматической обработки открой редактор и прослушай трек на скорости 0.5x–0.75x.
5. Выбери слово и нажми `S` в момент его начала, `E` — в момент окончания. Стрелки сдвигают слово на 10 мс, `Shift` + стрелка — на 100 мс.
6. Нажми «Проверить», затем скачай точный или совместимый ELRC.

## Проверка без тяжёлых моделей

```powershell
python -m unittest discover -s tests -v
```

Тесты проверяют парсер, миллисекундную точность, метаданные, offset, восстановление таймингов и обратимый импорт/экспорт ELRC.
